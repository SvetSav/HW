# Skystore
Это веб-приложение на Django, представляющее собой интернет-магазин цифровых товаров (плагины, примеры кода). 
Проект разработан в учебных целях и включает в себя главную страницу с каталогом и страницу контактов с формой обратной связи.

### Функциональность
- Главная страница с отображением товара (карточка с ценой, описанием и кнопкой «Купить»).

- Страница «Контакты» с контактной информацией и формой обратной связи.

- При отправке формы данные выводятся в консоль.

- Адаптивная вёрстка с использованием Bootstrap (подключён через CDN).

### Требования
- Python 3.10 или выше

- Django 6.0 и выше (указан в requirements.txt)

- Виртуальное окружение (рекомендуется)

### Установка и запуск
1. Клонируйте репозиторий (или скопируйте файлы проекта)
2. Создайте и активируйте виртуальное окружение

python -m venv venv   
venv\scripts\activate

3. Установите зависимости:

pip install -r requirements.txt

4. Выполните миграции (создаёт служебные таблицы Django):

python manage.py migrate

5. Запустите сервер разработки:

python manage.py runserver

6. Откройте приложение в браузере:

Главная страница: http://127.0.0.1:8000/

Страница контактов: http://127.0.0.1:8000/contacts/

### Использование
На главной странице отображается один товар (для демонстрации). Кнопка «Купить» в текущей версии неактивна.

На странице «Контакты» вы можете заполнить форму обратной связи (имя, телефон, сообщение) и отправить её. 
После отправки появится сообщение об успехе, а данные будут выведены в консоль, где запущен сервер.

Навигация между страницами осуществляется через меню в шапке сайта.

### Примечания

Bootstrap подключён через CDN, поэтому интернет-соединение требуется для корректного отображения стилей.
Форма обратной связи реализована без сохранения в БД, только вывод в консоль.
