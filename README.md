# Skystore
Это веб-приложение на Django, представляющее собой интернет-магазин цифровых товаров (плагины, примеры кода). 
Проект разработан в учебных целях и включает в себя главную страницу с каталогом,
страницу контактов с формой обратной связи, а также административную панель для управления товарами и категориями.

### Функциональность
- Главная страница с отображением товара (карточка с ценой, описанием и кнопкой «Купить»).
- Страница «Контакты» с контактной информацией и формой обратной связи.
- Административная панель для управления категориями, товарами и контактными данными.
- Полноценная работа с базой данных PostgreSQL.
- Модели данных: категории, товары, контакты.
- Автоматическое создание тестовых данных через кастомную команду.
- При отправке формы данные выводятся в консоль.
- Адаптивная вёрстка с использованием Bootstrap (подключён через CDN).

### Требования
- Python 3.10 или выше
- Django 6.0 и выше (указан в requirements.txt)
- PostgreSQL
- Bootstrap 5
- IPython
- Pillow (для работы с изображениями)
- python-dotenv (для переменных окружения)
- Виртуальное окружение (рекомендуется)

### Установка и запуск
1. Клонируйте репозиторий (или скопируйте файлы проекта)
2. Создайте и активируйте виртуальное окружение

python -m venv venv   
venv\scripts\activate

3. Установите зависимости:

pip install -r requirements.txt

4. Создайте файл .env в корне проекта на основе .env.example - cp .env.example .env

5. Отредактируйте .env, указав свои параметры подключения к базе данных в соответствии с .env.sample

6. Войдите в PostgreSQL и создайте базу данных:

CREATE DATABASE skystore_db;   
CREATE USER skystore_user WITH PASSWORD 'your_password';   
GRANT ALL PRIVILEGES ON DATABASE skystore_db TO skystore_user

7. Выполните миграции (создаёт служебные таблицы Django):

python manage.py migrate

8. Создайте суперпользователя - python manage.py createsuperuser

9. Запустите сервер разработки:

python manage.py runserver

10. Откройте приложение в браузере:

Главная страница: http://127.0.0.1:8000/

Админ-панель: http://127.0.0.1:8000/admin/

Страница контактов: http://127.0.0.1:8000/contacts/

### Использование
На главной странице отображается один товар (для демонстрации). Кнопка «Купить» в текущей версии неактивна.

На странице «Контакты» вы можете заполнить форму обратной связи (имя, телефон, сообщение) и отправить её. 
После отправки появится сообщение об успехе, а данные будут выведены в консоль, где запущен сервер.

Навигация между страницами осуществляется через меню в шапке сайта.

Административная панель:
После входа в админ-панель доступны следующие возможности:

Категории — добавление, редактирование, удаление категорий товаров.

Продукты — управление товарами, фильтрация по категориям, поиск по названию и описанию.

Контакты — управление контактной информацией, отображаемой на странице контактов.

Кастомные команды:
Загрузка тестовых данных - python manage.py load_test_data
Команда удаляет все существующие данные и загружает новые из фикстур (categories.json и products.json).

### Примечания

Bootstrap подключён через CDN, поэтому интернет-соединение требуется для корректного отображения стилей.
Форма обратной связи реализована без сохранения в БД, только вывод в консоль.
